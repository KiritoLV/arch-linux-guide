# 游戏只有 70 fps 上不去：GPU 满载，不是参数没调好

!!! info "一句话"
    先拿到基线数据，再谈优化；本机 PBZ 的天花板就是 GPU 满载。

## 现象

2560×1440 下 70 fps 左右，GPU 占用 92–95%，CPU 只有 30%，怎么调启动项都没变化。

## 环境

RTX 4060 Laptop 8 G / 170 Hz / PBZ / MangoHud 记录 383 秒。

## 排查

```bash
# 记录一次，然后按下面这些指标判瓶颈
nvidia-smi --query-gpu=utilization.gpu,clocks.sm,temperature.gpu,power.draw --format=csv -lms 1000
```

## 原因

GPU 已经满载（92–95%），帧时间由渲染本身决定（13.5–14.4 ms），不是调度问题。

## 解决办法

本机基线（PBZ，game 档，170 Hz）：

| 指标 | 数值 |
|---|---|
| fps 平均 / 1% low | 69–73 / 36–43 |
| 帧时间 中位 / p99 | 13.5–14.4 ms / 20–22 ms |
| GPU 占用 / 频率 | 92–95% / 2419–2490 MHz |
| GPU 温度 / 功耗 | 81–87 ℃ / 81–84 W |
| CPU 温度 | 92 ℃ 均，峰值 97 ℃（负载仅 30%） |
| >33 ms 的帧 | 308 秒里 10 个（0.05%） |

→ 帧节奏本身很干净，**提帧只能降画质/换机**；CPU 温度是散热侧问题，与显卡无关。

## 怎么确认好了

任何「优化」都要用同一场景前后对比 fps、1% low、p99 帧时间三项；单项变好不等于整体变好。
