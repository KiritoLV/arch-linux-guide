# 内核参数里两项各出现两次

!!! info "一句话"
    功能上无害，但说明有两个地方都写了 —— 顺手清掉，避免以后改了一个以为生效了。

## 现象

`cat /proc/cmdline` 里 `gpu_unlock.targets=all` 和 `nvidia.NVreg_DynamicPowerManagement=0x00`
各出现两遍（第 6/7 项与第 14/15 项）。

## 环境

GRUB + Arch。

## 排查

```bash
tr ' ' '\n' < /proc/cmdline | nl        # 一眼看出重复
grep -nE 'GRUB_CMDLINE' /etc/default/grub
```

## 原因

`GRUB_CMDLINE_LINUX` 和 `GRUB_CMDLINE_LINUX_DEFAULT` 各写了一份，生成配置时被拼接。

## 解决办法

只保留 `GRUB_CMDLINE_LINUX_DEFAULT` 里那一份，然后重建：

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

（涉及 sudo 与引导，命令自己跑。）

## 怎么确认好了

重启后 `tr ' ' '\n' < /proc/cmdline | sort | uniq -d` 为空。
