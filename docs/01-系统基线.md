## 根文件系统

```
btrfs  rw,relatime,compress=zstd:3,ssd,discard=async,space_cache=v2,subvol=/@
```

- `compress=zstd:3`：全局压缩，别为单个目录再折腾 nodatacow（收益接近零）。
- `discard=async`：靠 btrfs 自己发 TRIM，**不要**同时开 `fstrim.timer`。
- swap = **zram 29.1 G（zstd）**，不是磁盘分区；`zswap.enabled=0` 是有意的（zram 已经占了这个位置）。

## 内核参数逐条（`cat /proc/cmdline`）

| 参数 | 作用 | 谁加的 |
|---|---|---|
| `root=UUID=… rootflags=subvol=@ rw` | 从 btrfs 的 `@` 子卷启动 | 安装时 |
| `nvidia-drm.modeset=1` `nvidia_drm.fbdev=1` | NVIDIA 接管 KMS + fbdev，Wayland 必需 | 手动 |
| `gpu_unlock.targets=all` | GPL 张量解锁模块在驱动前加载 | `gpumode perf` |
| `nvidia.NVreg_DynamicPowerManagement=0x00` | 关 RTD3：让 dGPU 不断电（解锁是易失的，断电即清） | `gpumode perf` |
| `zswap.enabled=0` | 显式关掉 zswap，避免和 zram 抢 | 手动 |
| `clearcpuid=514` | 屏蔽某个 CPUID（AMD 平台兼容性） | 手动 |
| `modprobe.blacklist=sp5100_tco` | 屏蔽 AMD 看门狗，避免和 systemd 抢 | 手动 |
| `loglevel=5` | 少打印启动日志 | 手动 |
| `pcie_aspm.policy=powersave` | PCIe 省电策略 | 手动 |

**已知小问题**：`gpu_unlock.targets=all` 和 `nvidia.NVreg_DynamicPowerManagement=0x00` 在 cmdline 里
**各出现两次**（第 6/7 与 14/15 项）。功能上无害，但说明有两处都写了 —— 大概率是
`/etc/default/grub` 里 `GRUB_CMDLINE_LINUX` 和 `GRUB_CMDLINE_LINUX_DEFAULT` 各写了一份。
要清理的话只改 `GRUB_CMDLINE_LINUX_DEFAULT`，然后 `sudo grub-mkconfig -o /boot/grub/grub.cfg`。
