# 测延迟测出 0.0002 s：透明代理劫持了连接

!!! info "一句话"
    dae 在本地接管流量，TCP connect 直接返回，测出来的是本地假值。

## 现象

`curl -w %{time_connect}` 或自写脚本测 TCP 延迟得到 0.0002 s，比同城还快一百倍。

## 环境

dae 透明代理常驻；测速脚本走普通 `socket.connect`。

## 排查

```bash
ss -tlnp | head                  # 有没有本地监听在目标端口
ip route get <目标IP>            # 是否被重定向到 dae0 / 本机
curl -s -o /dev/null -w '%{time_connect}\n' https://example.com   # 与 ICMP 对比
```

## 原因

透明代理在 TCP 层就终止了连接，`connect()` 只连到本机端口，真实 RTT 藏在代理的后续转发里。

## 解决办法

测真实网络延迟要么绕过代理（指定绑定的网卡/直连路由），要么直接用 ICMP：

```bash
ping -c 8 <目标IP>
# 或者明确走物理网卡
curl --interface <iface> -s -o /dev/null -w '%{time_connect}\n' <url>
```

## 怎么确认好了

ICMP 与 TCP 两种方式量级一致（本机实测 Oracle 大阪 93 ms、新加坡 231 ms）。
