# 高刷下窗口偶发单帧花屏（NVIDIA）

!!! info "一句话"
    170 Hz 桌面，任意窗口偶尔有一帧花掉，截图和录屏抓不到。

## 现象

窗口内容偶发闪一帧错位/花块，几十分钟一次；不是整屏，是单个窗口。

## 环境

niri + NVIDIA 独显扫描输出 + 高刷新率；上游同类问题 niri #2030。

## 排查

先排除掉频（见《桌面滑动一顿一顿》），确认不是 DVFS 后再怀疑同步：

```bash
nvidia-smi --query-gpu=clocks.sm,pstate,clocks_throttle_reasons.active --format=csv,noheader
```

## 原因

NVIDIA 侧帧完成与 DRM 提交之间缺少显式同步，高刷下偶发一帧用了未渲染完的缓冲。

## 解决办法

```kdl
debug {
  wait-for-frame-completion-before-queueing
}
```

本机历史：2026-11-20 为花屏开过；2026-11-21 锁频消除掉频后又关掉做 A/B；
2026-11-24 因为 Chrome 跨卡撕裂重新开，只放在 game 档（见该条）。

## 怎么确认好了

观察一两小时没有单帧花屏；同时确认帧率没有明显下降（代价见《跨卡合成导致撕裂》那条的 A/B 数据）。
