# 录不到系统声音 / `pw-record --target` 指定了却没生效

!!! info "一句话"
    `--target` 写错不会报错，会**静默退回默认麦克风**；抓系统音要用 monitor 源。

## 现象

想录系统正在播放的声音，录出来是麦克风（或者一片静音）。

## 环境

PipeWire + WirePlumber；`pw-record` / `ffmpeg`。

## 排查

```bash
pactl list short sources | grep -E 'monitor|monitor'   # 找 <sink>.monitor
pactl get-default-sink
```

## 原因

`--target` 只是提示，设备名写错时 PipeWire 会回退到默认输入源且**不打警告**。

## 解决办法

```bash
# 系统音（走默认 sink 的 monitor）
ffmpeg -f pulse -i "$(pactl get-default-sink).monitor" out.wav

# 指定设备时必须先核对名字
pactl list short sources
pw-record --target <准确的源名> out.wav
```

## 怎么确认好了

录出来的波形有内容（`ffmpeg -i out.wav -af astats` 或直接放一遍）。
