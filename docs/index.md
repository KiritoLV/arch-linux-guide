# Arch 上的排错笔记

混合显卡 + niri 的机器上，显卡相关的问题基本只有**三类**，其他都是这三类的变体：

1. **跨卡合成**：niri 在一块卡上扫描输出、客户端在另一块卡上渲染，缺显式同步 → 闪屏 / 撕裂 / 残影 / 单帧花屏。
2. **静默偶发卡顿**：频率掉进深睡档，升频来不及 → 几秒顿一下，没有任何日志。
3. **跨卡首帧失败**：跨卡那条 dma-buf 导入路径没建立好 → 游戏黑屏但声音正常，成功一次后就不再犯。

Chrome 的硬解是这两类问题的**常见触发器**：Chromium 不支持 NVIDIA 硬解，独显直连只能软解；有核显时改指核显，硬解是有了，但立刻引入跨卡合成。
