# 个人 Arch Linux 使用指南

一台 **ASUS TUF Gaming A15 FA507XV**（R9 7940HS + RTX 4060 Laptop + Radeon 780M）上的
Arch Linux 实战记录：混合显卡、niri 合成器、Chrome 硬件解码、VRR、性能调优、排错。

不是入门教程 —— 是**这台机器上真实踩过的坑和实测数字**。写作原则：

1. 只写实测结论，推断一律标注；
2. 每条结论给**判据命令**，方便半年后自己复核；
3. 写因果链（因为 A 导致 B，在 C 条件下出现 D），不写「试这个」。

> 环境：Arch Linux / 内核 `7.3.5-zen1-1-zen` / niri `26.04` / nvidia-open-dkms `620.73.04` /
> mesa `26.3.1` / Chrome `158`。硬件不同时结论未必成立，但判据命令照样能用。
