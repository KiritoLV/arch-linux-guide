# 碰到的问题，以及怎么解决的

这里放我在 Arch Linux（混合显卡 + niri）上真实碰到的问题：**现象 → 排查 → 原因 → 解决办法**。

每条都按同一模板写，带可复制的判据命令，方便以后自己（或别人）照着复查，而不是给一句「试这个」。

> 环境：Arch Linux / 内核 `7.3.5-zen1-1-zen` / niri `26.04` / nvidia-open-dkms `620.73.04` / mesa `26.3.1` / Chrome `158`。硬件不同结论未必成立，但判据命令照样能用。

## 写作约定

1. 只写**实测**结论；推断标「推断」并写清排除过程。
2. 每条给**判据命令**，能自己复核。
3. 写因果链：因为 A 导致 B，在 C 条件下出现 D —— 不写「试这个」。
4. 涉及 `sudo`、引导参数、分区的操作只写命令，不代跑。
