# 09 排错手册

> 出事先看这张表，认准症状再动手。每条的完整因果链在对应章节。

## 显示 / 显卡

| 症状 | 第一动作 | 往下看 |
|---|---|---|
| **黑屏 / 怀疑显卡挂了** | `DRI_PRIME=1 timeout 30 vkcube --c 5` | 03 |
| 窗口偶发单帧花屏（高刷、NVIDIA） | game 档的 `wait-for-frame-completion-before-queueing` 是否在；再看是否掉频 | 03 §4/§6 |
| 桌面「滑一下先卡、然后顺、几秒后又卡」 | DVFS 升频慢：`timeout 16 nvidia-smi --query-gpu=clocks.current.graphics,utilization.gpu -lms 100 --format=csv` 看「占用已 90%、时钟还是空载档」 | 03 §6 |
| 游戏只有 70 fps、GPU 占用 92%+ | 正常，GPU 满载是硬瓶颈，不是故障 | 03 §8 |
| 游戏里感觉顿挫但帧数不低 | 先查 `vrr_enabled`，再查游戏内 vsync | 03 §5 |
| VRR 明明配了却没生效 | `niri msg --json windows` 看 `app_id` 是不是 `*.exe` | 03 §5 |
| CPU 温度 90 ℃+ 但 CPU 占用只有 30% | 散热侧问题（共享热管），与显卡无关 | 03 §8 |
| 风扇狂转 | 先确认不是在解帧率限制/满载跑分 | 03 §3 |

## Chrome

| 症状 | 第一动作 | 往下看 |
|---|---|---|
| 硬解没生效（`Decoding:` 是空的） | 是不是跑在 4060 上？Chromium 主动跳过 `nvidia-drm` | 03 §3 |
| **全软件渲染、`GL_VENDOR: Disabled`** | 检查 `chrome-flags.conf` 里有没有 `--use-gl=egl`（Chrome 158 非法值），删掉 | 03 §3 |
| 弹幕残影 / 撕裂 | 780M 渲染 + niri 4060 扫描输出的跨卡撕裂，靠 game 档 workaround | 03 §4 |
| CPU 突然降低但画面更差 | 别把「CPU 降低」当优化证据，先确认 GPU 没被整个关掉 | 03 §3 |

## niri / 合成器

| 症状 | 第一动作 |
|---|---|
| 改了配置没反应 | `niri validate -c ~/.config/niri/config.kdl` → `niri msg action load-config-file` → `journalctl --user -b \| grep "niri_config: loaded"` |
| 切换档位后起不来 | 顺序错了：**先改配置 → 再换线 → 最后退出登录重进** |
| 所有 X11 程序一起挂 | 别在热加载时移除 `ignore-drm-device`（会让 xwayland-satellite panic） |
| `niri msg` 报 `NIRI_SOCKET is not set` | `NIRI_SOCKET=$(ls /run/user/$(id -u)/niri*.sock \| head -1) niri msg …` |

## 存储 / 文件

| 症状 | 第一动作 | 往下看 |
|---|---|---|
| NTFS 读到一半 EIO / 中断 | 是 `fs/ntfs` 老驱动的已知 bug（7.3.6 修） | 04（待写） |
| NTFS 卷报 dirty | `ntfsfix` / `ntfsinfo -f`；Arch 的 `ntfsprogs` 里**没有** `ntfsck` | 04 |
| 磁盘满 | 先 `du -sh /var/cache/pacman/pkg`（本机 11 G） | 02 |
| 全盘扫描卡死 | 放弃全扫，改用 `stat` / `filefrag` / 定点 `od` | 04 |

## 音频

| 症状 | 第一动作 |
|---|---|
| `pw-record --target` 指定设备没生效 | 设备名写错会**静默退回默认麦克风**，不报错；先 `pactl list short sources` 核对 |
| 想录系统音 | `ffmpeg -f pulse -i "$(pactl get-default-sink).monitor"` |

## 网络

| 症状 | 第一动作 |
|---|---|
| 测速快得离谱（TCP connect 0.0002 s） | dae 透明代理劫持了 curl，假值；结论必须标明是否绕过代理 |
| 某个服务连不上但浏览器正常 | 见 `proxy-app-connectivity-diagnostics` 技能 |

## 更新 / 系统

| 症状 | 第一动作 |
|---|---|
| 更新后某个东西坏了 | `grep -E 'upgraded' /var/log/pacman.log \| tail -30` 看这次动了几个组件，别先怪显卡 |
| 要回到旧版本 | `/var/cache/pacman/pkg` → ALA，见 02 |
| 内核参数被谁加了一项 | `tr ' ' '\n' < /proc/cmdline` |
